ローカルで動かす方法


1.VS Code を起動します。
上部メニューの 「ファイル」 ＞ 「フォルダを開く…」 を選択します。
ダウンロードしたプロジェクトのフォルダ（package.json などのファイルが入っている場所）を選んで開きます。

2.ターミナル（コマンド入力画面）を開く:
VS Code の上部メニューにある 「ターミナル」 ＞ 「新しいターミナル」 をクリックします。
画面の下側に黒い（または白い）文字入力エリアが現れます。
開いたターミナルに以下のように入力し、

npm install

Enterキーを押します。



.env ファイルを作る
1. VS Code の左側（ファイル一覧）の余白部分を右クリックし、
「新しいファイル」 を選択します。

2. ファイル名を .env （ドット・イー・エヌ・ブイ）にしてEnterキーを押します。

3. 開いた画面に以下のように書き込み、保存（Ctrl + S または Cmd + S）します。

GEMINI_API_KEY=ここに取得したAPIキーを貼り付け


4.再び下のターミナルで以下を入力して Enterキー を押します。


npm run dev


ターミナルに http://localhost:3000 または http://localhost:5173 などのURLが表示されます。

0.0.0.0 という番号は、サーバー（プログラム）側の「どの接続でも受け付けますよ」という特殊な設定用の記号なので、ブラウザの検索窓（URL欄）にそのまま打ち込んでも開けないことが多い.
その場合は、ブラウザのアドレスバーに、0.0.0.0 の代わりに localhost を使って入力してみてください。


お使いのブラウザ（Google Chromeなど）を開きます。

アドレスバーに http://localhost:3000 と入力してEnterを押します。

アプリの画面が表示されれば成功です！ 🎉
